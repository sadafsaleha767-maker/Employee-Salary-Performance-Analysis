# Employee Salary & Performance Analysis
## 📌 Project Overview
This project focuses on analyzing employee salary and performance data using Microsoft Excel.
The project covers data cleaning, analysis, employee distribution, salary analysis, performance analysis, and experience-based analysis to generate useful business insights.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Excel Formulas
* Pivot Tables
* Data Visualization
* Business Insights

## 📊 Project Highlights

* Cleaned and prepared employee data
* Checked missing values and duplicate records
* Analyzed employee distribution
* Performed salary analysis
* Analyzed employee performance
* Analyzed experience-related data
* Created summary analysis for business insights

## 📁 Project Files

* `Employee_Salary_Performance_Analysis.xlsx` — Complete Excel project
* Project screenshots — Analysis and visualization outputs

## 💡 Key Learning

Through this project, I practiced converting raw employee data into meaningful analysis using Excel and developed practical skills in data cleaning, analysis, visualization, and business insight generation.

## 👩‍💻 About Me

I am an aspiring Data Analyst building my skills through practical, project-based learning.

I am currently developing my knowledge in Excel, SQL, Power BI, Python, data cleaning, data analysis, and data visualization.

I am continuously working on real-world style projects to build my Data Analyst portfolio.
